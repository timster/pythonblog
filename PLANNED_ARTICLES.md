# Planned Articles

## Article Types

| Type | Description |
|------|-------------|
| **Plain** | Standalone deep dive on a Python concept or language feature. The core format — explain it, show real patterns, summarize. |
| **Series** | Multi-part connected articles on a larger topic. Each part should stand alone but reward readers who follow the whole series. |
| **Package Highlight** | Showcase a specific Python package. Format: what it is → install → killer feature → real-world pattern → when not to use it. |
| **Comparison** | Two approaches, libraries, or tools side by side. Very searchable ("X vs Y"). Focus on when to reach for each, not just feature lists. |
| **Tutorial** | Build something end-to-end from scratch. More guided than a Plain article — reader follows along and has a working artifact at the end. |
| **TIL** | Short "Today I Learned" format. A single surprising or non-obvious Python behavior or trick. Good for maintaining cadence between longer posts. |
| **Cookbook** | A collection of patterns or recipes for a specific use case (e.g. "10 ways to flatten a list"). Skimmable, reference-style. |
